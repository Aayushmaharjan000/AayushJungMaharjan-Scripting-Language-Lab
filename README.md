# Lab-1 JavaScript Solutions (Questions 1–39)

Each question is a standalone HTML file (`q01.html` – `q39.html`) with the JavaScript
embedded in a `<script>` tag. Just double-click any file to open it in your browser.

- **Q1–Q26**: Function-based answers. Output shown both in the browser page and in
  the browser console (press F12 to view).
- **Q27**: DOM manipulation — see the `q27/` folder (`index.html` + `script.js`).
- **Q28–Q39**: Full mini-apps (challenge tracker, prime/even/odd grids, countries
  table, counter, calculator, analog/digital clock, cookie manager, table row
  clone/delete, button-controlled paragraph, and a validated registration form).

## For your lab report
For each question:
1. Copy the relevant JS into your hand-written "Code" section.
2. Open the `.html` file in your browser, take a screenshot of the result, and
   paste it into the "Output" section (include the file's local URL, e.g.
   `file:///.../q05.html`, or your GitHub Pages URL if hosted).
3. Push each numbered file to your GitHub repo as instructed, with a new branch
   for this lab set, and share it with instructor.basanta@gmail.com.
